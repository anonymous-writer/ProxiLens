# ProxiLens 2.1.0 Beta 10 – Integration Preview

This preview builds on the Beta 9.2 source tree. It adds a tested action-scoped
approval model and integration engineering notes. It does not yet install or
enable PAM, Polkit, sudoers or a privileged authorization endpoint.

See `docs/integration/BETA10-INTEGRATION-STATUS.md` before testing. Run the
read-only host check with `bash scripts/proxilens-integration-preflight.sh`.
